Privacy policy

Gmail integration is in development. This describes its intended data handling when enabled.

Access & purpose

For accounts authorized by the owner, the application will access the account address, message identifiers, sender and recipient headers, subjects, dates, short body previews and labels such as unread, starred and important. It uses these to display messages, remember review choices, synchronize changes and move explicitly confirmed selections to Gmail's Trash. Full bodies and attachments are not intended to be downloaded for the review list.

The requested permission is gmail.modify. Google's permission includes sending capability; the application does not provide sending or permanent deletion features.

Storage & control

Message summaries, previews, review preferences and history will be stored locally on the owner's PC. Authorization tokens must be encrypted at rest. Account-removal controls must allow removal of cached mail and account-specific review history before connections are enabled. The owner controls any separate local copies.

Access can be revoked through Google Account connections. Revocation stops further access but does not erase local copies. Gmail controls Trash retention and recovery.

Use & sharing

Mail data is used only for the owner's visible personal-review features, including saved choices that may improve suggestions. It is not sold, used for advertising or used to train generalized AI models. No external AI processing is enabled. Changes to data use will require updated disclosures and consent before use.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website & contact

These static pages contain no mailbox data, forms or analytics scripts. GitHub Pages processes hosting requests, including IP addresses for security, under the GitHub Privacy Statement.
