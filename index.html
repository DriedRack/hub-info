Personal Automation Hub

A private desktop application for reviewing Gmail messages.

The application runs locally on its owner's PC. Gmail integration is in development and is intended solely for the owner's accounts. Selected messages will move to Gmail's Trash only after confirmation.

This website provides app information for Google account authorization. It does not provide access to the application or any email.
